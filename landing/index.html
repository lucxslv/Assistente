SEGURANÇA POR DESIGN

Nenhum comando roda às cegas no seu Windows.

Diferente de scripts desgovernados ou assistentes na nuvem que tentam executar comandos remotos de forma opaca, o Charlie opera com Aprovação Atômica. O Permission Engine intercepta cada chamada Win32/PowerShell antes de tocar o sistema.

✓
Auditoria Criptográfica Indelével: Cada comando autorizado gera uma entrada com timestamp, parâmetro original e hash de validação no banco local.
✓
Isolamento de Memória SQLite: Suas mensagens, histórico e embeddings vetoriais residem localmente na sua máquina, sem telemetria em servidores externos.
✓
Proteção contra Injeção de Prompt: Verificador semântico bloqueia tentativas de jailbreak e execução de código fora do workspace selecionado.

DÚVIDAS FREQUENTES

Perguntas & Respostas Técnicas

O Charlie utiliza o Permission Engine Zero-Trust. Nenhuma tool de escrita em disco, manipulação de processos ou comando PowerShell é executada automaticamente sem que um card de aprovação atômica apareça na tela para o usuário. Você pode permitir uma única execução, aprovar a meta inteira ou recusar a qualquer momento.
O Context Drawer é o painel lateral retrátil integrado ao Charlie Desktop. Ele centraliza quatro módulos cruciais em abas: o Hub de Ativos (arquivos e subagentes ativos), o Git Diff Review (onde você revisa e aceita ou reverte alterações no código), os Terminais e Logs em tempo real, e a visualização de Artefatos gerados pela IA.
Não. A base de dados do Charlie (memória histórica, threads, indexação semântica e configurações) é armazenada localmente em um banco SQLite criptografado no seu próprio disco. Apenas as mensagens explícitas de prompts enviadas durante o chat transitam pela API do modelo de linguagem configurado (Google Gemini), com suporte total para rodar 100% offline via Ollama.
O Modo Chat funciona como um diálogo de texto rápido com streaming fluido para dúvidas de programação, resumos e brainstorming. Já o Modo Agente Autônomo projeta uma árvore de tarefas, cria planos com checkpoints de validação, coordena subagentes e executa passos concretos com verificação de evidências até atingir a meta.
O Spotlight é uma janela ultraleve e transparente registrada com o atalho global Ctrl + Space. Ela surge sobre qualquer jogo ou aplicativo ativo sem roubar foco permanente, permitindo que você comande seu computador por voz ou texto instantaneamente.
